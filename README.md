# Frontend

This is the React/Vite frontend. For the full application startup steps, backend setup, optional AI service, and integration notes, see the [handoff guide](../README.md).

To run only the frontend in development mode, install dependencies and start Vite:

```powershell
pnpm install
pnpm dev
```

For standalone demo mode, follow the instructions in the handoff guide. For the normal connected application, start the backend as described there first.
